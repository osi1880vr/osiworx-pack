# Changelog

## 0.1.0 (unreleased)
- First module `layer`: `LayerStream: H3 Chunking` (MiniMax H3, bit-identical output) and `LayerStream: Krea2 Chunking`
  (Krea 2, numerically equivalent output). See `layer/README.md` for measurements and limits.
- Module `wos`: `Megapixel Size` (width/height for a megapixel budget from an input image). The H3 test workflow uses it.
- Two test workflows, example launcher scripts.
